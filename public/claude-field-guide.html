Which Model Should I Use?

Think of these as four levels of expertise. You wouldn't hire a barrister to post a letter, and you wouldn't ask a temp to handle your tax return. The model decides how smart the thinking is. Effort (next tab) decides how long it thinks.

💡Rule of thumb: Start with Sonnet 5 for everyday work. Step up to Opus 5 when you need serious analysis. Fable 5 is rarely needed by most people.

What's a token?
A token is roughly ¾ of a word. So 1,000 tokens ≈ 750 words. A typical email is ~200–400 tokens. A full A4 page of text is ~500–700 tokens. Claude reads your message (input tokens) and writes a reply (output tokens) — both count toward your usage.

Effort Levels — How Hard Claude Thinks

The model is who you hired. Effort is how long you let them think before answering. Higher effort = more "thinking tokens" used = better answers on hard problems, but slower and uses more of your plan.

💡Where to find it: The effort slider is next to the model selector in claude.ai. You can change it mid-conversation. Default is High.

Chat vs Cowork vs Code

Three different surfaces, three different jobs. They all use the same Claude models — the difference is what Claude can access and do.

Chat
What it is
The conversation interface on claude.ai, the mobile app, or the desktop app. You type, Claude responds. Can search the web, create files, build interactive tools, connect to apps.
✓ Use for
Most things. Questions, writing, research, creating documents, getting advice, learning.
✗ Not for
Multi-step file work on your computer, or automated recurring tasks.
Examples
Writing emails, blog posts, plans · Analysing documents · Getting advice · Creating spreadsheets, reports.
Cowork
What it is
Claude as a desktop coworker. Reads/writes files autonomously. Runs scheduled tasks. Connects to apps. Builds live dashboards.
✓ Use for
Delegating work: file processing, reports, dashboards, automation, morning briefings.
✗ Not for
Quick questions — Chat is faster.
Examples
"Update all filenames in this folder" · "Build a dashboard" · "Process these invoices" · Automated morning briefings.
Code
What it is
A terminal-based coding agent for professional developers. Sees your codebase, writes code, runs commands, manages git. You won't need this unless you're a developer.
✓ Use for
Professional software development.
✗ Not for
Non-coding tasks. If you're not in a terminal, this isn't for you.
Examples
Building web apps · Refactoring codebases · Running tests.

Projects — Persistent Workspaces

A Project is a walled-off workspace with its own files, instructions, and conversation history. Every new chat inside that project starts with full context — so you don't re-explain things every session.

When to use a Project

Use a project when you have a recurring topic with context that doesn't change much between sessions. Upload files and instructions once — every new chat inherits them automatically.
Good examples: Your business brand guidelines · A subject you're studying · A client you work with regularly · Your CV and job applications · Planning a wedding or event · Managing a rental property

When NOT to use a Project

Don't create one for one-off questions. Project files eat context window space. Regular chat with memory is simpler for everyday use.
💡Projects vs Memory: Memory remembers things about you across all chats automatically. Projects remember things about a topic — only within that project. Use both.

Artifacts vs Live Artifacts

An artifact is what Claude produces for you — not just text in the chat, but an actual rendered thing you can see, interact with, download, or share.

Artifact (Standard)
A standalone piece of content in a side panel: a document, web app, chart, tool, game, recipe card — anything worth seeing rendered rather than as plain text.
When to use
Any time Claude produces something you'd want to preview, edit, download, or share.
Key difference
It's a snapshot you iterate on in conversation. Can be published and shared via link — no Claude account needed to view.
Examples
A working calculator · A formatted CV · An interactive quiz · A meal planner · A budget tracker · A comparison chart
Live Artifact
A persistent dashboard that refreshes with current data every time you open it. Built in Cowork, saved in your sidebar. Pulls live data from connected apps.
When to use
You want a dashboard that stays current without re-prompting. Something you open daily and it shows today's numbers.
Key difference
Standard artifacts = frozen snapshots. Live artifacts = today's data today. Desktop-app only. Version history saved automatically.
Examples
A sales dashboard · An email summary that refreshes each morning · A project tracker · A calendar overview

Scheduled Tasks & Dispatch

Automation features inside Cowork. They make Claude do work without you sitting there watching.

⏰Scheduled Tasks
Set a task to run automatically at a time you choose. Give it a prompt, connect the tools it needs, pick the schedule. Claude runs it and the results are waiting when you arrive.
Examples: A morning email digest at 7:30am · A weekly sales summary every Friday · A daily calendar briefing
📱Dispatch
A remote trigger. Type a prompt on your phone → it fires into a full Cowork session on your computer. Same files, same context, same apps. Your laptop needs to be awake.
Think of it this way: Scheduled = set a timer. Dispatch = press a button from anywhere.
Routines (newer): Cloud-hosted automation that runs even when your laptop is closed. Good for tasks that must fire 24/7 regardless of whether your machine is on.

The Simple Decision Tree

1. Quick, simple question? → Haiku or Sonnet + Low effort
2. Writing, planning, or moderate thinking? → Sonnet + Medium effort
3. Detailed work (long writing, strategy)? → Sonnet + High effort (default)
4. Sonnet not cutting it? → Step up to Opus 5
5. Genuinely the hardest problem? → Opus 5 + Max effort (Fable rarely needed)
6. Should it happen automatically? → Cowork + Scheduled Task
7. Need a dashboard that stays current? → Cowork + Live Artifact
8. Recurring work with stable context? → Put it in a Project
